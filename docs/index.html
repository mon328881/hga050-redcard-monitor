滚球红牌监控

在已登录的 hga050 滚球页运行。书签网址必须以 javascript: 开头，不能是本安装页的 https 地址。

为什么一点书签就跳回安装页？

手机把本安装页收成了书签（网址是 https://…github.io/…），所以会打开这个网站。正确书签的网址必须是 javascript: 开头的一长串代码，点了之后人还在 hga050，只是弹出监控面板。

正确安装（必做：改书签网址）

  1. 1点下面红色按钮，复制书签代码
  2. 2先随便收藏一页（本页或 hga050 都行），名称改成「红牌监控」
  3. 3打开书签 → 编辑 → 把「网址 / URL」全部删掉，粘贴刚复制的代码 → 保存
  4. 4检查网址是不是以 javascript: 开头。如果是 https://，说明没改对，会继续跳走
  5. 5打开并登录 hga050.com，进入滚球 → 足球，再点这个书签

Android Chrome

  • 星标收藏 → 书签管理 → 点那条右侧菜单 → 编辑
  • 网址栏粘贴代码。若保存后 javascript: 消失，换 Via 浏览器 或 Firefox + 油猴

iPhone Safari

  • 分享 → 添加书签 → 书签列表点「编辑」→ 点这条 → 改地址
