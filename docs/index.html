手机系统浏览器不允许保存脚本网址，所以会提示「网址不符合规范」。请改用 Via，装的是普通 https 脚本，进入滚球后会自己出现面板。

不要再改书签网址

Chrome / 小米 / 华为 / OPPO 都会拦截 javascript:。伪装成 https 也过不了。下面这条安装链接是真的 https，可以收藏。

手机这样装

  1. 先安装 Via 浏览器（官网 viayoo.com）
  2. 用 Via 打开本页，点红色按钮复制脚本
  3. Via 右上角 ≡ → 设置 → 脚本 → 添加脚本：匹配填 *hga050.com*，内容粘贴刚才复制的代码，保存并打开开关
  4. 仍用 Via 打开并登录 hga050.com，进入滚球，等 2 秒出现监控面板
