不要点「打开脚本文件」。请用下面复制完整脚本，在 Via 里手动添加。已去掉易导致解析失败的中文标题和 @match。

推荐安装（Via 手动添加）

  1. 安装 Via（官网 viayoo.com）
  2. 用 Via 打开本页，点红色按钮复制
  3. Via → 设置 → 脚本 → + 添加
  4. 匹配规则留空（脚本里已带网址），把复制内容整段粘贴到脚本框 → 保存 → 打开开关
  5. 用 Via 打开并登录 hga050.com，进滚球，等约 2 秒出现面板
